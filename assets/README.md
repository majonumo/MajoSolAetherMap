# Repository assets

The original author image is stored at `assets/majo-and-sol.png`. The build copies the unchanged PNG into the plugin package, and the About window loads that packaged relative path at runtime while preserving its aspect ratio.

Repository screenshots belong in `assets/screenshots/`:

- `main-window.png`
- `map-overlay.png`
- `settings.png`

Only include artwork and screenshots that Majo & Sol own or are permitted to redistribute. Do not commit extracted Final Fantasy XIV textures or other proprietary game resources.
