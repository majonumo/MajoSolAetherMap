# Majo & Sol Aether Map v0.7.0

First public release of Majo & Sol Aether Map for Dalamud API 15.

## Highlights

- Real Aether Current progress for the current zone and selectable supported zones.
- Exploration-current coordinates and native map flags.
- Aether Current quest names, quest NPCs, locations and completion state.
- Passive multi-marker overlay synchronized with the native FFXIV map.
- Compact FFXIV-inspired interface in English and Spanish.
- Configurable marker filters, size, opacity and debug information.
- About window featuring the official Majo & Sol artwork.

## Installation

Download `latest.zip`, extract it to a folder, and install `MajoSolAetherMap.dll` through Dalamud's developer plugin locations. The package must remain intact so the About artwork can be loaded from `assets/majo-and-sol.png`.

Use `/aethermap` to open or close the main window.

## Verification

SHA-256 checksums are attached in `SHA256SUMS.txt` and documented in the repository.
